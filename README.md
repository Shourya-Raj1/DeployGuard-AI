
# DeployGuard AI

## About
DeployGuard AI is an AI-powered software deployment risk assessment platform.

It analyzes software changes before deployment to identify potential risks and provide useful recommendations.

## Objectives
- Identify potential deployment risks.
- Analyze code changes.
- Highlight potentially affected services.
- Recommend relevant tests.
- Generate deployment risk reports.

## Technology Stack
- Python
- Git and GitHub
- FastAPI
- Machine Learning
